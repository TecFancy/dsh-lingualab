# LinguaLab 使用指南

[English](usage.md) | 简体中文

这份文档按用户实际使用的顺序讲这个面板：首页、添加素材、剧集与分段、视频、练习、笔记与复习、设置。想知道面板怎么用就读这里；为什么这样设计，见 `.agents/notes/`。

## 首页负责选集，练习视图负责逐句听

页面打开后先显示**首页**：上次听的那一集、其余剧集和一个拖放区。点任意一集即可打开。进入一集后会切换到**练习**视图，点返回按钮就能回到首页。

## 拖入文件就能添加素材

把音频和字幕拖到页面上，或者点「选择文件」。字幕按文件名配对：

- 文件名以音频文件名开头的字幕归这个音频。例如，`s01e01.en.srt` 和 `s01e01.zh.srt` 都归 `s01e01.mp3`。
- 只有一个音频和一个字幕时，不论文件名是什么，都算一对。
- 可以一次拖进很多集。服务端把每一集放进媒体目录下各自的文件夹，**绝不覆盖已有的文件**，也会说明跳过了哪些文件。

库里还什么都没有时，首页只显示拖放区。用户不必先弄懂什么是媒体目录。

## 媒体库按集建文件夹，支持常见音视频和字幕格式

素材根目录下，一集一个文件夹。文件夹里放音频、最多两份字幕，以及可选的 `notes.md`。导入生成的也是这个结构：

```text
notes/learning/english/media/
  S01E01/
    audio.mp3
    S01E01.en.srt
    S01E01.zh.srt
    notes.md
```

扫描接受六种音频（`.mp3`、`.m4a`、`.wav`、`.ogg`、`.opus`、`.flac`）、四种视频（`.mkv`、`.mp4`、`.webm`、`.mov`）和三种字幕（`.srt`、`.vtt`、`.lrc`）。

只有一个字幕文件、内容里又有中文时，它同时作为英文和中文字幕，因为双语字幕本来就是一个文件里有两种语言。既没有音频也没有视频的文件夹照样会列出来，只是不能播放。

根目录可以放一份 `manifest.json`，用来指定播放顺序、修改剧集标题、指定先打开哪一集。

## 两个及以上音频仍是一集，按分段播放

一个文件夹里有**两个及以上音频**时，这些音频组成一集里的多个分段：

- 一个音频是一段，按自然顺序排列，`02` 在 `10` 前面。
- 每一段按文件名配自己的字幕，字幕归音频名最长的那一段。例如，`04_Dunphy家-Luke射击.srt` 不归名为 `04_Dunphy家` 的同级音频。
- 文件名里带 `双语` 或 `bilingual` 的字幕（如 `01_Dunphy家的早晨_双语.srt`）同时包含两种语言。其中的中文行作为中文字幕；英文字幕取标了英文的那份，没有就取唯一一份没标语言的，再没有就仍用这个文件。
- 页面一次播放一段。顶栏的按钮列出全部分段，一段听完会提示下一段。
- 一集仍然只有一份 `notes.md`，每一段在里面有一个 `## <分段名>` 标题。

## 视频和音频共用同一条练习时间线

**视频是同一段的另一个来源。** 视频按字幕的规则与音频文件配对。例如，`MDJT S01E01.mkv` 归 `MDJT S01E01.mp3`，有多个候选时取音频名最长的。没有音频文件与之配对的视频单独成为一段，声音取自视频。只有一个词干的文件夹仍然是一集一段。

首页的卡片和分段列表上有一个小的视频标记，视频还没准备好时显示「视频 · 未准备」。浏览器本来就能播放的视频会直接播放，包括 `mp4` 或 `webm`，画面编码为 H.264、VP9 或 AV1，声音编码为 AAC、Opus 或 MP3。

其余视频**在用户需要时准备一次**，入口是「准备视频」：

- `ffmpeg` 原样复制画面，把声音转成立体声 AAC，取第一条英文音轨，没有就取第一条。生成的 `mp4` 把索引放在文件开头，耗时和读一遍文件差不多。
- 浏览器无法解码 HEVC、MPEG-4 Part 2、10 位 H.264 等画面时，这一步不会重新编码画面，只把声音提取成 `m4a`。这样，没有独立音频文件的分段照样能精听。要把这类画面变成能播放的视频，需要使用下面的流畅版。
- 准备好的文件放在隐藏的 `<剧集>/.lingualab/` 文件夹里，先写成 `.part` 再改名。源文件从不改动，删掉这个文件夹只需要重新准备一次。
- 服务端一次只跑一个准备任务，任务有进度，也能「取消」。`PATH` 里要有 `ffmpeg` 和 `ffprobe`，也可以在可选的 `ffmpegPath` 配置里指定两者所在的文件夹，或其中任一个的路径。这是宿主配置里的 volatile 字段，运行中也能写入，所以在插件页改完不用重启。
- 没有这两个程序时，`mp4` 和 `webm` 仍然直接播放，其余视频显示一张带安装命令的卡片。

一段有了能播放的视频，播放器就用视频作为来源，练习听到的也是视频的声音。隐藏画面时，有独立音频文件的分段改为播放音频文件，不再下载视频。字幕、循环、收藏的句子、调整时间和复习都在同一条时间线上照常工作。

舞台上的画面有三种状态：显示、大画面、隐藏。状态和其他设置一起存在这个浏览器里，`V` 键和播放卡片里的按钮可以在三者之间切换。大画面里按 `R`，当前句的英文会显示在画面上，直到下一句开始。

五步法只在盲看计时这一处用到画面。开始计时会切到大画面，并显示一条「撤销」提示；暂停计时或把这一步标记完成后，画面回到之前的状态。

视频只在媒体库里播放。从工作区其他位置选来的视频，只有不需要准备时才播放，和调整字幕时间的范围一致。

## 流畅版降低码率，减轻网络负担

**流畅版**适合带不动原画质的网络。你可以按一集或一段手动点「准备流畅版」，入口在正在播放的画面角上，或者在需要准备、画面无法解码的视频卡片上。旁边写着预计体积和耗时：约 1.9 Mbps，在服务器上约为实时的 1.5 倍。这些数字只是估计。

`ffmpeg` 把画面重新编码成 H.264，使用 `veryfast`、CRF 23，码率上限 1.8 Mbps，像素格式为 8 位 4:2:0，高度不超过 720 行，更小的画面保持原尺寸，每 2 秒一个关键帧。声音转为 128 kb/s 的立体声 AAC。结果写成 `<剧集>/.lingualab/<词干>.smooth.mp4`，索引在文件开头。

流畅版和视频准备共用同一个一次一个的任务，进度和「取消」也一样。任务以较低的优先级运行，线程数比机器核数少一个。这期间画面照常播放；任务失败或你取消任务时，一切保持原样。

流畅版生成后，页面会删掉原尺寸的准备文件 `<词干>.mp4`，能直接播放的源文件从不改动。页面按流畅版、准备版、源文件的顺序选择播放来源。

正在播放流畅版时，画面上有「改回原画质」。点击后会删掉流畅版，再把视频按原来的方式准备一次。换封装约一分钟；画面无法解码的视频会回到只有声音的状态。

## 本地文件无需上传即可播放

有视频的段还可以**播放用户自己电脑上的文件**。点画面上或任意视频卡片上的「用本地文件播放」，或者把文件拖到舞台上即可。本地文件会在同一次会话里代替服务器上的视频播放，不会上传，因此不受慢网络影响。

页面会比较本地文件和服务器上视频的时长。服务器上的视频还没探测过时，就和音频文件比较。相差超过一秒会显示同样的时长警告。

`mp4`（H.264 加 AAC）在哪里都能播放，`mkv` 常常没有声音。浏览器无法解码的文件会退回服务器上的来源。

浏览器能提供文件句柄时（Chromium），页面会按段把选择记在这台设备上，下次点一下就能接着用；其他浏览器每次都要重新选。这些信息都不会发送给服务端。

## 媒体目录可以浏览选择，也支持绝对路径

首页底部用不起眼的一行显示文件位置，旁边有「更改」。设置目录不用手动输入路径，主要入口是「浏览已有的文件」：进入目标目录，点「用作媒体库」，服务端会自己解析路径。

绝对路径输入框仍然保留，给工作区之外、无法浏览进去的挂载点用。保存时通过设置服务把 `libraryRoot` 写进插件的 profile 条目，所以这个值只存在一处，也不用重启。

## 散装音频也能单独成为一集

一集不一定是一个文件夹。媒体库根目录里的散装音频，或者任何可浏览位置下的音频文件，都能单独打开。「浏览已有的文件」会列出这些音频，并按文件名配对字幕。服务端记住文件后，就能提供文件内容，也有地方保存笔记。

## 练习围绕句子进行，并记住每集进度

练习以句子为单位，不以文件为单位：

- 播放卡片上只留每分钟都要用的控件：上一句、下一句、播放、变速、循环本句、中文显示和星标。A-B 区间、重复次数、提前起播（每句提前一点开始播放）和快捷键一览收在「更多」里。
- 点字幕行就跳到那一句并开始播放。变速有十档，不改变音调。点倍速按钮会列出全部十档，点一下就选好；`=` 回到 1×，再按一次回到之前的倍速。
- 双语字幕不论源文件怎么排列，英文总在上、中文在下。中文有四档显示模式，避免用户不自觉地去读母语。
- 页面记住每一集听到哪里、五步法勾了哪几步，首页的「接着上次」会从记住的位置继续播放。

进度记录存在服务端，即媒体库根目录里隐藏的 `.lingualab-progress.json`，和各集的 `notes.md` 放在一起。每个浏览器另有一份缓存，所以换一台设备、开无痕窗口、清掉浏览器缓存，都能接着上次听。两台设备的记录不一致时，以最近一次停下的位置为准。媒体库文件夹本身如果在同步（网盘、git 仓库），进度也会跟着同步。

## 练习视图把舞台、字幕和跟读放在一起

练习视图是一个舞台加一栏字幕。舞台上是大号的当前句，前后句以淡色显示在周围。右栏列出每一句，随播放滚动，并标出收藏过的句子；关掉「自动跟随」后就不再跟着滚动。

- 进度条横跨整集，每一句的起点有一道细刻度。悬停时显示指针处的时间和那一句；拖动时只在松手时跳转一次。拖动时手指离开进度条，速度就降到一半，再到四分之一。
- 点英文单词可以复制，或者记进那一句的备注，音频不会停。拖过几个词，或者按住 `Shift` 点第二个词，对两者之间的词组也一样。再点一次「已记下」就去掉。
- **跟读**模式每句播完就停，页面先把英文模糊遮住，停下时揭开，随时按 `R` 也能揭开。
- 在「更多」里，跟读可以按复读程序运行：每句播一到三遍，每遍后留出复述停顿，时长和这句一样，或者一句半，再加一秒，还可以自动进入下一句。开了停顿，英文会一直遮住，直到第一遍复述结束。提示条显示「该你说」，并随剩余时间逐渐填满；再开自动下一句，整页不用动手就能一直练下去。
- 在同一处打开「录下我说的」，每次复述停顿都会录音。停顿一结束，先重放一遍原句，再播放刚才的录音，之后随时点「对比」按钮或按 `D` 重放这一对。录音只存在内存里，只保留这一集打开期间每句的最后一遍，不保存、不上传，也不打分。录音需要 HTTPS 页面（localhost 也可以）和浏览器允许使用的麦克风。无法满足这些条件时，开关会自动关闭并给出提示，复读程序照常进行。
- 练习视图打开期间，耳机、AirPods 和锁屏通过浏览器的 Media Session 充当复读机的实体按键。播放和暂停等同于播放按钮，在复述停顿里按，会在这句的开头结束程序。上一首、下一首分别后退或前进一句；复习时是在队列里后退和跳过一条。锁屏上显示这一句和这一集的名字。页面有意不提供「跳过几秒」的按钮，所以上一首、下一首始终是切句。这项功能一直开着，使用的也不是键盘快捷键，因此不影响 dsh 的按键。

听到结尾会出现小结，附带下一集的入口。播放器下面的按键标签会为页面刚处理的那个键亮一下。系统设置了「减少动态效果」时，所有动效都会关闭。

## 星标收藏句子，评级决定复习范围

**收藏一句只需要点星标**：播放卡片上有，每一行字幕上也有，也可以按 `S`。再点一次就取消。

收藏的句子位于右栏的另一个视图「收藏」，和字幕并列，按 `N` 切换。点一张卡片，那一句就放上舞台循环播放；舞台上那一句的卡片会展开，显示备注、单词和评级。备注可以写多行，`Ctrl+Enter` 保存，卡片上的时间按钮可以播放和暂停这一句。

每句收藏只有一个状态，按 `1`「记住了」、`2`「模糊」或 `3`「没记住」设定。评为「记住了」的句子会离开「还在练」视图，但仍保留在收藏里。还在练的句子因此能保持精简，靠的是用户自己评级，而不是数量上限。

**复习**把还在练的句子逐句过一遍：英文先遮住，按 `R` 揭晓，每句循环播放，直到评级为止。可以在「收藏」栏为这一集开始复习，也可以在首页的卡片上为整个库开始。

文件夹剧集的笔记是 Markdown 清单，一条短语占一行。备注里的换行写成 `<br>`，所以一条短语始终占一行。这份笔记既能直接在编辑器里阅读，也方便 Agent 用 grep 检索，第二天复习时就能派上用场。文件剧集的笔记存在插件自己的 profile 里，因为这个插件除了加入用户交给它的文件之外，不往素材目录里写别的东西。

## 收起右栏可以让舞台占满宽度

点顶栏「收藏」旁边的面板图标，或者按 `\`，右栏就会收起，舞台占满整个宽度，画面也随之变大。iPad 上舞台原本只有 440 到 630px 宽。

右栏收起时按 `N` 或点「收藏」，会直接展开到收藏；展开到字幕时，列表定位到正在播放的那一句。是否收起和下面的设置一样，存在这个浏览器里。

空间较窄时，例如 iPad 竖屏，或者横屏时 dsh 侧栏展开，右栏会改成盖在舞台上的抽屉。点抽屉外面或按 `Esc` 就收起。按过一次开关之前，空间窄时右栏默认收起，空间宽时默认展开。

## 设置只影响当前页面

**设置**是首页和练习页顶栏最右边的滑块图标。点开是一个抽屉，只影响这一页，不改 dsh 本身。可以设置：

- 主题：「默认」「墨蓝」「松绿」「纸张」「暮紫」「高对比」，各有浅色和深色两套配色。
- 明暗：跟随 dsh，或者固定为一种。
- 舞台上当前句的字号。
- 提前起播。

主题会在页面根元素上设置 dsh 自己的颜色令牌，所以页面以外的东西都不受影响。这些选择存在这个浏览器里，换一台设备就从默认值开始。
