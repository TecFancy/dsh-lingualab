# 当前状态

[English](status.md) | 简体中文

这份文档记录已经做成了什么、页面怎么从左栏「更多」菜单打开，以及改动如何发布。改入口的注册方式，或者判断某个能力是否存在时，先读它。

## 服务端和前端都已完成

服务端提供媒体库扫描、导入路由、支持 `Range` 的媒体路由、可浏览的目录选择浮层、笔记读写和复习清单；前端提供首页、练习视图、「收藏」栏与复习，以及目录浏览浮层和媒体目录设置浮层。

## 页面注册为 `main` 面板，左栏没有单独一行

这一页**不在左栏占一行**，也不在「应用」页上占一张卡片。它以 `main` 面板的形式注册在 `lingualab` 这个键上，入口是左栏「更多」菜单里的第一行。这个插件自己把入口注册进 `sidebar.panellist.actions`，点击后调用 `layout.selectPanel('lingualab')`。入口由插件自己注册，所以左栏不必为每个插件各加一行，也不再依赖 `dsh-apps-panel`。

## 改动先合入 `development`，再通过 `main` 发布

开发在 `development` 分支进行，改动合进 `main` 就是一次发布；随后发布流程打 tag、发到 npm。具体命令和 CI 的执行流程，见[发版](releasing.zh.md)。
