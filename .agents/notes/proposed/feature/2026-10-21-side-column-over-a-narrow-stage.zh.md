# Agent Note: 练习栏窄时，侧栏浮在舞台上并默认收起

Status: proposed

## Problem

在 iPad 上，练习栏只有 440 到 630px 宽，因为宿主的侧栏占了 56px 或 280px，字幕栏又占了 260 到 440px。2026-10-21
定下的第一步，是让用户能把侧栏收起来：三种状态（收起、字幕、收藏），顶栏加一个开关，选择按设备记住。

做完这一步还剩两种情况：

- 在窄的练习栏里（iPad 竖屏，或横屏时宿主侧栏展开），为了查一句而打开字幕，会占走舞台的宽度，
  于是画面、句子和播放卡片每次都要变成窄布局，再变回来。
- 第一次在 iPad 上打开插件的用户，还没找到开关就先看到了窄布局。

这两个想法是在同一次讨论里提出的，留到以后再做：先把收起做出来，用一段时间，再决定下一步。

## Proposal

- **栏窄时浮在舞台上。**
  - 当舞台和侧栏共用的那一行很窄时，展开的字幕或收藏从右边以抽屉的形式盖在舞台上，带一层遮罩，
    和「五步」抽屉一样，不再占用舞台的宽度。抽屉下面的舞台保持宽布局。
  - 点遮罩、按 `Esc` 或按开关都能关掉抽屉。
  - 那一行够宽时，侧栏仍然和现在一样排在舞台旁边。
  - 阈值看的是那一行（`ll-body`）的宽度，不看窗口，理由见布局那篇 note。
- **栏窄时默认收起。** 设备上还没有存过选择时，那一行窄就默认收起，宽就默认展开。用户按过一次开关之后，以存下的选择为准，
  不再看宽度。

## Alternatives considered

- **只做收起，不做抽屉。** 这是先上线的部分，也许已经够用：在 iPad 上收起侧栏的用户，可能很少再打开它。只有在窄栏里反复打开、关闭侧栏
  变得很常见时，抽屉才值得做。
- **收起时留一条约 40px 的窄条。** 侧栏随时一按就能展开，但占用的恰好是最缺的宽度，而顶栏的开关已经能做到一按展开。
- **只看宽度，不存选择。** 更简单，但想在 iPad 上一直看字幕的用户就没法让它保持展开；宿主侧栏一展开、布局就跟着变，也会让人意外。
- **竖屏时用底部弹出面板。** 适合手机，但 iPad 竖屏时舞台本来就是上下排列的，底部面板会盖住播放卡片，而布局那篇 note
  最优先保证的就是播放卡片留在屏幕上。
