# Agent Note: 给右栏的展开收起加动画，并重排顶栏那一排按钮

Status: proposed

## Problem

0.15.0 让右栏可以收起了：右栏要么不画，要么排在舞台旁边，舞台把宽度拿回去。展开和收起都在一帧里完成。这是有意的，
[右栏可以收起](../../implemented/feature/2026-10-21-collapse-the-side-column.zh.md)那篇 note 否掉了宽度动画，
因为动画的每一帧舞台都要重排（画面、播放卡片的行数、调整时间的布局），而那正是收起想消除的跳动。

用了一天之后，这个切换读起来像一次跳跃。眼睛看着列表里的某一句，按下 `\` 给舞台腾地方，落到画面上时画面已经动完；
右栏回来时又是一下子出现，也没有任何东西说明它落回的那一句就是刚才在播的那一句。变化太硬，两个状态像两页不同的页面，
而不像同一行里有一块被藏起来了。

顶栏有一类同样的问题，只是发生在空间上。它装着返回按钮、带分段行的标题、分段选择器、收藏 chip、右栏开关、五步和设置。
0.15.0 让返回和收藏在窄于 720px 时只留图标，并给每个按钮补到 44px 的点按区域，但这一排仍然没有分组：两个作用于右栏的
按钮夹在分段控件和步骤追踪器中间，设置、五步和右栏开关之间也没有任何顺序说明它们各属于谁。这一排是按「放得下什么」排的，
不是按「什么属于一起」排的。

## Proposal

- **给右栏一个短过渡。** 展开和收起用 160 到 220 毫秒：右栏的宽度和不透明度一起变，舞台的份额在同一个过渡里跟上，
  画面随着右栏长大或缩小，而不是等它变完再跳一下。`prefers-reduced-motion` 下仍然直接切换。
- **右栏消失之后就卸载。** 退场动画跑在一个包装层上，里面还是当前那份列表；动画结束后包装层移除。重新挂载、落回正在播的
  那一句这些行为都不变。
- **按「这个控件作用于什么」重排顶栏。** 收藏 chip 和右栏开关并成一组，与剧集控件（返回、标题、分段）分开，
  也与这一集的进度（五步）分开。五步和设置挪到最右边自成一组，低频的可以收进一个「更多」。44px 的点按区域、
  窄于 720px 只留图标、标题让位，以及 `N`、`\` 的提示都照旧。
- **先量再定动画形式。** 那篇 note 反对的是每一帧的代价。在真的 iPad 上录一次展开和收起的动画帧。宽度动画能守住帧预算就用它；
  守不住就只做不透明度，让舞台在最后一次性落定。记工作过程的那篇 note 要写清选了哪一种、为什么。

## Alternatives considered

- **保持直接切换。** 这是现在的决定，也最省；否掉它是因为这个要求是用了之后提出来的，跳一下正是用户注意到的毛病。
- **只淡入淡出，宽度直接跳。** 比动宽度便宜，但两个状态之间差 260 到 440px，右栏看起来还是弹出来，舞台也还是跳。
- **动舞台，不动右栏。** 出现和消失的是右栏；只动舞台会让没有变化的那一半动起来。
- **右栏保持挂载、只动它的宽度。** 能留住滚动位置，但藏起来的列表不会跟随正在播的句子，原来的决定也正是因此不留着它。
- **把顶栏的文字多藏一些。** 省的是像素，不是层级；按钮依然按一个每次都要重新读的顺序排着。
- **把顶栏的控件全塞进一个「更多」菜单。** 顶栏是安静了，但收藏和右栏开关每次会话都要用，菜单每次多一次点按。
