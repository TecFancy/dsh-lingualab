# Agent Note: 点一下就选好倍速

Status: proposed

## Problem

控制栏上的倍速按钮每点一下升一档，到最高一档后回到最低一档。一共十档（0.5、0.6、0.7、0.8、0.9、1、1.15、1.25、1.5、2），
所以要点几下取决于想去哪一档，而想调慢总要先绕过所有更快的档位：

- 从 1× 到 0.6× 要点六下，中途经过 2×；
- 从 2× 回到 1× 要点六下，把慢的档位全走一遍；
- 多点一下就要绕一整圈：还得再点九下，才能回到本来想要的那一档。

`[` 和 `]` 一档一档地调慢、调快，不会绕圈，用键盘时好一些，但远距离跳转仍然是一档按一下，而 iPad 上根本没有键盘。
对学习者来说，调倍速是很频繁的动作（遇到难句放慢，听完再调回来），所以这些点击次数每次练习都要付很多遍。

用户在 2026-10-23 提出这个问题，要一个方案，以后再做。

## Proposal

**倍速按钮弹出一个选择框，点一下档位就选中。**

- 按钮上照旧显示当前倍速。点它会在上方弹出一个小弹层，和「字幕」一样，十个档位都排成小按钮：先是慢的几档，
  然后是 1×，和两边稍微隔开，方便点中，最后是快的几档。当前倍速带描边。
- 点一个档位就切到这个倍速，弹层随即关上。任何倍速都只要点两下，点错了再点两下就改回来。
- 关闭方式和「字幕」一样：在弹层外按下或按 `Esc`，之后焦点回到倍速按钮。按另一个弹层的按钮也算在外面按下，
  所以同一时间只开一个弹层。
- 每个档位按钮至少 44px 高，方便在 iPad 上用手指点。
- 循环切换去掉之后，绕圈也一起去掉：`nextSpeedWrapping` 不再有人调用，删掉。

**`=` 回到 1×，再按一次回到之前的倍速。**

- 当前不是 1× 时，`=` 切到 1×。
- 当前是 1× 时，`=` 切到上一次用过的、不是 1× 的倍速，不管它当时是怎么选的（选择框、`[` `]` 或 `=`）。
  这样「放慢、回原速、再放慢」每个方向都只要按一个键。还没用过别的倍速时，`=` 不起作用。
- `=` 是页面没有用到的键，在美式键盘上就挨着 `[` 和 `]`，三个键可以当成一组来记。`[` 和 `]` 的含义不变。
  快捷键表里写成 `[  ]  =`，说明文字写变慢、变快和原速。
- 记住的倍速放在播放器的 store 里，挨着当前倍速。和当前倍速一样，换剧集时保留，刷新页面就没了。

**怎么拆。** 选择框是控制栏 widget 里一个单独的组件（`ui/SpeedMenu.tsx`），因为 `ControlBar.tsx` 已经到了体量门的上限，不能再加。
弹层的打开、关闭和「在外面按下就关上」的逻辑合成 widget 的 `lib/` 里的一个 hook，「字幕」弹层、「更多」菜单和新的选择框都用它。
这样 `ControlBar` 里那两段重复的 effect 就拿掉了，它反而比现在短。按键是页面键盘表里新加的 `speed-reset` 动作；
按下后切到哪一档，由当前倍速和记住的倍速算出来，是一个纯函数，有自己的测试。

## Alternatives considered

- **在倍速两边放减号和加号按钮。** 点错了点一下就能改回来，但远距离跳转仍然是一档点一下：从 1× 到 0.6× 要点四下。
- **滑块。** 拖一下就能到任何倍速，但用手指很难正好停在某一档上，而且控制栏上没有它要的那么多空间。
- **把所有档位一直摆在控制栏上。** 完全不用弹层，但十个按钮和这一行的其他控件放不到一起。
- **长按或双击按钮回到 1×。** 屏幕上没有任何东西告诉用户有这个功能；而且双击会先触发一次单击，倍速会先变一档再被重置。
- **只在几个常用倍速之间循环。** 点的次数少了，但要另加一个设置来选哪几个常用，而且常用之外的倍速就没法从按钮上选到了。
- **`=` 只回到 1×。** 更简单，但遇到难句放慢、听完调回原速的学习者，每次想再放慢都得打开选择框。
