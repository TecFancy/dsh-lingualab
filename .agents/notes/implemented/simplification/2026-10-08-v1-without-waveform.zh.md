# Agent Note: 第一版不做波形、视频和跟读评分

Status: implemented

## Problem

已经废弃的独立应用有波形、十档变速、A-B 区间、PWA 外壳和离线缓存，它自己的待办清单里，接下来要做的是视频
支持和发音打分。把这份清单原样搬进面板，就会重蹈那个应用的覆辙：它根本没被用起来，工具做得很完整，练习的习惯却没有
养成。

## Decision

第一版只做四件事：播放、循环当前句、变速、双语字幕加笔记。不做波形，不做内嵌视频，不做跟读评分。
盲看那一步用外部播放器看素材，口语练习留在会话里和 agent 一起做。

## Alternatives considered

- **把波形搬过来。** 它是旧应用里最显眼的功能，代价是一个三百 KB 的依赖，要么懒加载、单独分包，要么打进
  每次页面加载。等字幕列表确实不足以找到要听的段落时再考虑。
- **内嵌视频。** 文件在 NAS 上，而且很大；内嵌意味着要通过家里宽带的上行发送 Range 请求，还要多一条时间轴和字幕
  保持同步。
- **用本地识别给跟读打分。** 识别器已经装好，每次调用也不花钱，但它会在习惯还没养成之前，就把听力练习变成
  打分循环。

## Consequences

推迟的每一项都已经确定了将来放在哪一层：波形是字幕面板旁边的一个 widget，视频是同一个 store 背后的另一种
媒体来源，评分是一个读取本地识别结果的 feature。它们都不需要先改动 store 或者两端之间传输数据的契约。
