# Agent Note: 第一版不做波形、视频和跟读评分

Status: implemented

## Problem

废弃的独立应用有波形、十档变速、A-B 区间、PWA 外壳和离线缓存，它自己的待办里排在后面的是视频
支持和发音打分。把这串清单原样搬进面板，等于重演那个应用没能被用起来的原因：工具很完整，习惯没
养成。

## Decision

第一版只做四件事：播放、循环当前句、变速、双语字幕加笔记。不做波形，不做内嵌视频，不做跟读评分。
盲看那一步用外部播放器看素材，口语练习留在会话里跟 agent 做。

## Alternatives considered

- **把波形搬过来。** 它是旧应用里最显眼的东西，代价是三百 KB 的依赖，要么懒加载分包，要么压进
  每次页面加载。等字幕列表确实不够用来找段落时再说。
- **内嵌视频。** 文件在 NAS 上而且很大，内嵌意味着跨家庭上行的 Range 请求，还要多一条时间轴跟字幕
  对齐。
- **用本地识别给跟读打分。** 识别已经装好、单次不花钱，但它会在习惯还没养成之前，把听力练习变成
  打分循环。

## Consequences

推迟的每一项都已经有了归属：波形是字幕面板旁边的一个 widget，视频是同一个 store 背后的另一种
媒体源，评分是一个读本地识别的 feature。它们都不需要先改动 store 或者线上契约的形状。
