# Agent Note: 入口挪到启动台，左栏那一行跟着撤了

状态：已落地

## Problem

这一页原来在左栏占一行，order 是 40，排在插件、自动化任务、应用、技能下面。左栏当时一共五行，
而每多一个带页面的插件就再多一行：不管这一页是不是你自己会去导航的地方，左栏都要用宽度为它付账。

「应用」本来就是那个地方——一个列出你打开的东西的启动台。语言实验室正是其中之一，
而它还是那里唯一一个另有一扇门的条目。

## Decision

撤掉 `sidebar.panellist` 那段注册，`main` 继续挂在 `lingualab` 这个 key 上。入口改成「应用」页上
的一张卡片：`dsh-apps-panel` 的注册表里有一条，`panel` 字段写着这个 key，点卡片调的是
`ctx.layout.selectPanel('lingualab')`——和左栏那一行调的完全是同一个东西。

`retainMainPanels` 保留的是每个被 `main` 条目认领的 key，所以撤掉那一行不会让选中的面板退回会话。

## Alternatives considered

- **两个入口都留着。** 一间屋子两扇门。左栏还要继续为一行付账，而那一行唯一的差事就是链到
  启动台已经列出的页面。
- **加一个配置开关在两者之间选。** 客户端半边得先读到插件配置才能决定要不要注册那一行，
  于是多一次往返，行的出现也会晚一拍。换来的是一个谁也没遇上的场景：这个插件都装在启动台在的地方。
- **让启动台向这个插件要一张卡片。** 那是一个只有一个调用者的跨插件扩展点，而且它把条目挪进代码，
  可启动台注册表的用意正是让主人不碰 bundle 就能改清单。

## Consequences

- 左栏图标（`src/client/icons/rail.tsx`）与文案里的 `panel` 键都没人用了，删掉。
- 这个插件从此要有 `dsh-apps-panel` 才进得去。没有它的 profile 里，页面注册着却没有入口；
  README 的「当前状态」一节把这件事写明了。
- `lingualab` 成了两个互不 import 的包之间的约定。字符串归这一侧所有，启动台那一侧把自己的半边
  写在 `scripts/check-host.mjs` 里。
