# Agent Note: 先有一个可以挑的首页，文件靠拖进来

Status: implemented

## Problem

第一次打开，页面是一个什么都没有的播放器。空状态讲的是插件自己的话：「媒体目录」、文本框里的绝对路径、
十三条候选路径，而且每一条都标着不存在。一个只是想来听一听的人，得先弄懂什么叫媒体目录，手工建好，
再把文件拷进去，页面才能做第一件事。有了素材也没有好多少：选一集要点顶栏上那个小小的标题，打开一层浮层，
在两个标签之间选，再一级一级浏览目录。

练习本身也有摩擦。运输条上有十三个控件，每分钟都要用的两个（播放、循环本句）和每次只用一回的
（A、B 点、重复次数）挤在一起。收藏一句要弹出输入框，一集的第八句还会弹出选择器，问七句里扔掉哪一句，
而那一句还在播着。

## Decision

**页面先落在首页，练习是第二个视图。** 首页把要接着听的那一集放得最大，其余剧集是点一下就打开的行，
再往下是添加更多的入口。打开一集就切到练习视图，它的返回按钮回到首页。原来选集的那层浮层没有了，
选择器只留下「浏览已有的文件」，给放在媒体目录之外的素材用。

**文件靠拖进来。** `POST /lingualab/import` 把一个文件当作原始请求体接收，剧集文件夹和文件名放在查询里。
页面按主机配对字幕用的同一条规则给一次拖入分组（字幕属于文件名是它前缀的那个音频，取最长匹配，
一个音频旁边孤零零的一个字幕不论叫什么都算一对），先发音频再发它的字幕，每个文件一次请求。
所以空库显示的是一个拖放区和一个按钮，一个字也不提文件夹。

**这是插件唯一往媒体目录里写东西的地方，而且很窄。** 它从不覆盖：名字已经存在就报告 `exists`，原文件不动。
只收扫描本来就读的那些扩展名。名字在主机上清洗，文件夹建好之后再确认它落在根目录之内，
所以指向别处的符号链接带不走这次写入。内容先进同一文件夹里的隐藏临时文件，写完整了才链接到位，
中断的上传不会留下一个看起来像音频的残件。请求必须带一个自定义头，跨站表单设置不了它。
单个文件上限 2 GB，页面查一次，主机再查一次。

**练习行上留六个控件。** 上一句、播放、下一句、变速、循环本句和中文显示留下；A、B 点和重复次数连同全部快捷键
一起收进「更多」菜单。

**收藏一句是开关，不是表单。** 运输条和每一行字幕上的星标收藏这一句，再点一次，或者按 `S`，就取消。
笔记放进抽屉，分「还在练」「已记住」和全部三个视图。一句记住了就打勾，它离开第一个视图，但不会被删掉。

**取消七条上限。** 笔记文件的格式不变。主机仍然拒绝超过 500 条的列表，只是为了不让失控的客户端写出
无限大的文件。

**页面记住你听到哪里**，每集一份，存在这个浏览器的 `localStorage` 里，播放时每五秒写一次，离开时再写一次。
首页用它来画「接着上次」那张卡。

## Alternatives considered

- **保留先谈文件夹的空状态，把说明写得更清楚。** 新读者仍然要先建目录、再拷文件，什么都没发生过。
  问题从来不在说明写得好不好，而在于需要说明。
- **自带一集生成的示例。** 第一分钟能跑起来，但学不到真实的流程，还要语音合成或者自带音频。
  拖一个真文件步数一样，而且走的就是之后一直要走的路。
- **保留上限，把替换选择器做得不那么烦。** 不管怎么包装，这条规矩都在最糟的时刻要一个决定。
  笔记列表上的筛选给出了上限想要的那个短的工作集，又不在一句话中间问任何问题。
- **大小不同就允许导入覆盖已有文件。** 猜错了的启发式会删掉别人的音频。报告 `exists` 然后不动文件，
  这个办法没有一种失败模式值得拿来换省下的那一次点击。
- **用 multipart 表单上传。** 一整集音频要在某一头整个缓冲进内存。原始请求体直接流进磁盘，上限固定。
- **把书签存到主机上。** 它能跟着人换浏览器，代价是多一条写入路由，还要在 profile 里给一个丢了也不心疼的东西
  找个位置。

## Consequences

- 「素材目录只读」这条规矩不再毫无例外。取而代之的更窄，也有检查：插件只写交到它手里的新文件，
  从不替换已有的，也从不写到根目录之外。扫描、浏览、打开这几条路径依然全是只读。
- 一集的文件夹以音频文件名命名，所以两次拖入同名的不相干文件会共用一个文件夹，第二次报告 `exists`。
  改名交给读者。
- 原来不超过七条的笔记文件不变，不做任何迁移。
- 书签是每个浏览器一份。换一个浏览器，每一集都从头开始，首页也看不到进度。
- 五百条收藏是可能出现的。抽屉里的几个视图能让它可以翻，要不要修剪是读者自己的事。
