# Agent Note: 练习栏窄时，侧栏浮在舞台上并默认收起

Status: implemented

## Problem

在 iPad 上，练习栏只有 440 到 630px 宽，因为宿主的侧栏占了 56px 或 280px，字幕栏又占了 260 到 440px。0.15.0
上线的第一步，是让用户能把侧栏收起来：三种状态（收起、字幕、收藏），顶栏加一个开关，选择按设备记住。

做完这一步还剩两种情况：

- 在窄的练习栏里（iPad 竖屏，或横屏时宿主侧栏展开），为了查一句而打开字幕，会占走舞台的宽度，
  于是画面、句子和播放卡片每次都要变成窄布局，再变回来。
- 第一次在 iPad 上打开插件的用户，还没找到开关就先看到了窄布局。

这两个想法是在同一次讨论里提出的，当时留到以后再做，先把收起做出来。

## Decision

- **那一行窄于 982px 就算窄。** 看的是舞台和侧栏共用的那一行（`.dsh-lingualab-body`）的宽度，不看窗口，理由见布局那篇 note。
  行宽不超过 820px 时侧栏是 260px，超过时是 `clamp(300px,34%,440px)`，所以行宽只要小于 982px，侧栏排在旁边就会让舞台小于
  648px，内容盒小于 600px，正是窄栏规则开始生效的地方。规则是 `pages/lingualab/lib/side-column.ts` 里的 `sideFloats`，
  `useSideFloating` 用 `ResizeObserver` 量这一行。
- **行窄时，展开的侧栏是一个抽屉。** 这一行带上 `is-side-floating`，侧栏从右边盖在舞台上，宽 360px（行太窄、留不出 48px
  舞台时更窄），侧栏和舞台之间有一层遮罩。顶栏不在这一行里，所以开关和「收藏」照常能按。舞台按侧栏收起时的布局排，
  抽屉打开时下面什么都不变。点遮罩、按 `Esc` 或按开关都能把侧栏收起；五步抽屉也开着时，`Esc` 先关五步。抽屉和遮罩
  盖在完成卡片（z-index 15）上面，在五步抽屉（21 和 22）下面，`prefers-reduced-motion` 时没有动画。
- **还没选过的设备跟着宽度走。** `sideCollapsed` 是 `true`、`false` 或 `null`，只有存下的布尔值才算选过。是 `null` 时，
  行窄就收起，行宽就展开，iPad 转屏或宿主侧栏开合时也跟着宽度变。
- **只有开关会存下选择。** 顶栏的开关和 `\` 总是把结果存下来。还没选过时，其余会改变侧栏的动作（`N`、「收藏」按钮、
  打开收藏的受保护句子、`Esc`、遮罩）只改这一次打开的状态。在 iPad 上看一眼收藏，不该让以后每次打开都弹出抽屉。
  选过之后，每个动作都照以前一样存下来。

## Measured

- 抽屉，用真实样式表在浏览器里量：行宽 764 和 540 时宽 360px，行宽 300 时宽 252px（留出 48px 舞台），上沿和这一行的上沿对齐，
  在顶栏下面。舞台占满整行，窄行规则里那条 260px 的宽度没有作用到抽屉上。
- 默认收起，用真实的 hook 和 React 在浏览器里用 `flushSync` 渲染：行宽 764、还没选过时，第一个任务结束时侧栏已经收起，
  量到宽度之前的两次展开渲染都没有画到屏幕上。接着按 `N` 弹出抽屉，什么都不存；按开关存下 `false`。行宽 1200、还没选过时，
  侧栏照常排在舞台旁边。

## Alternatives considered

- **只做收起，不做抽屉。** 这一步先在 0.15.0 上线了。有了收起之后，在 iPad 上打开侧栏仍然会把舞台挤成窄布局，
  而收起本来就是为了消除这种跳动。
- **收起时留一条约 40px 的窄条。** 侧栏随时一按就能展开，但占用的恰好是最缺的宽度，而顶栏的开关已经能做到一按展开。
- **只看宽度，不存选择。** 更简单，但想在 iPad 上一直看字幕的用户就没法让它保持展开；宿主侧栏一展开、布局就跟着变，也会让人意外。
- **每个动作都存，和收起那一步一样。** 状态更简单，但在还没选过的设备上，第一次按 `N` 就会存下「展开」，看一眼收藏之后默认收起就没了。
- **只靠样式表的容器查询决定要不要变成抽屉。** 布局做得到，但 `Esc` 和遮罩都要知道侧栏是不是浮着的。同一个问题有两个答案
  （一个查询、一次测量），在阈值附近可能不一致。
- **竖屏时用底部弹出面板。** 适合手机，但 iPad 竖屏时舞台本来就是上下排列的，底部面板会盖住播放卡片，而布局那篇 note
  最优先保证的就是播放卡片留在屏幕上。

设计参照，含竖屏下的浮层抽屉（只看比例，以宿主令牌为准）：<https://claude.ai/artifact/8xXbV93vDTvCdWoVhicX1s>。

## Consequences

- 在 0.15.0 下存过任何一项设置的浏览器，也存下了 `sideCollapsed: false`，因为每次写入都会存整条记录。这样的设备已经算选过，
  所以在窄行里打开时是抽屉，不是收起；按一次开关就会存下「收起」。
- 阈值是把样式表里侧栏的宽度又写了一遍。改侧栏的 `clamp` 或 820px 那条规则时，要一起改 `SIDE_FLOAT_BELOW`。
- 还没在 iPad 真机上看过，上面的测量都是在桌面浏览器里按 iPad 的宽度做的。
