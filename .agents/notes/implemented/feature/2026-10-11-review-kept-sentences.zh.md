# Agent Note: 复习收藏的句子

Status: implemented

## Problem

收藏一句只要点一下星标，这一步没有问题。问题出在收藏之后：

- 笔记抽屉是模态的。它的遮罩盖住了舞台和控制栏，翻看收藏时看不到字幕；从抽屉里重播的句子，在关掉抽屉之前甚至
  无法暂停（这一点已经单独修好，但根源在布局）。
- 一条收藏带着三个要手动维护的标记：表示「记住了」的勾，加上「#想不起」（`#review`）和「#还记不住」（`#hard`）
  两个标签开关。界面上没有说明三者是什么关系，三个标记的任意组合都可能出现。
- 没有复习功能。清单只是清单：要把收藏的句子一句句过一遍、每句听几遍，只能挨个点每张卡片。
- 复习只能按集进行，而学习方法并不是这样。新建的 `notes.md` 开头写着「想不起的加 `#review`，周日还记不住的加 `#hard`」，
  意思是每周把所有句子过一遍，页面却只能显示一集的句子。
- 在舞台上点一个词，它会以 `[word]` 的形式记进那一句的备注，但界面上没有办法再把它去掉：气泡显示「已记下」后就没有下文，
  卡片上的词显示成一个小标签，也没有删除的入口，只能手工编辑 `notes.md`。
- 一次只能选一个词。值得记下的往往是搭配或词组（「her skirt」「get down here」），却没有办法把它们作为一个整体记下。

## Decision

**右栏在「字幕」和「收藏」之间切换。**

- 去掉笔记抽屉和它的遮罩；收藏的句子占用字幕栏的位置，沿用字幕栏的宽度和滚动。舞台和控制栏始终可用。
- 顶栏的「笔记 n」和 `N` 键把右栏切到「收藏」，再按一次切回来。
- 点一张卡片和点一行字幕的效果一样，只是多了循环：那一句放上舞台，循环播放。
- 舞台上那一句的卡片高亮，而且只有这张卡片是展开的，它的备注、单词和评级都显示在里面，所以整个列表仍然是一列句子。
- 三个筛选视图（「还在练」「已记住」「全部」）保留，做成栏头的一个小分段控件。
- 五步的抽屉不在这次改动之内。

**一条收藏只有一个状态，由评级决定。**

| 状态 | 显示为 | 在 `notes.md` 里 |
|---|---|---|
| 新 | 「新收藏」 | `- [ ]`，两个标签都没有 |
| 模糊 | 「模糊」 | `- [ ]`，带 `#review` |
| 没记住 | 「没记住」 | `- [ ]`，带 `#hard` |
| 记住了 | 「记住了」 | `- [x]` |

- 评级的入口是展开的卡片上的三个按钮，以及三个键：`1`「记住了」、`2`「模糊」、`3`「没记住」。练习和复习时，
  它们都作用于舞台上那一句收藏。
- 新的评级替换之前的状态：先清掉勾和两个标签，再设上自己的。用户手写的其他标签保留。
- 卡片上去掉复选框和两个标签开关，只用一个小标签显示状态。
- `notes.md` 的行格式不变，所以旧文件和 agent 的 grep 都照常能读；两个标签都有的行读作「没记住」。
- 新建的 `notes.md` 开头的说明改为解释评级，不再解释标签。

**记下的词和词组可以撤回，词组可以作为一个整体记下。**

- 在舞台上，点一个词和原来一样选中它；拖过几个词，或者按住 `Shift` 点第二个词，会选中两者之间的整段。
  气泡里随即显示这段词组，同样提供「复制」和「记下」。
- 词组存成 `[her skirt]`。备注里的标记本来就允许这样写（`splitNote` 读取方括号之间的任何文本），所以格式不变。
- 「已记下」变成开关，再点一次就把词或词组移除；卡片上的每个小标签都带一个移除按钮。
- 移除一个标记只去掉 `[...]`，备注的其他内容不动。

**复习是练习页的一种模式。**

- 「收藏」栏头的「复习」为当前这一集开始复习。队列是这一集里还没「记住了」的句子，按播放顺序排列（先按段，再按时间）。
- 每一项放上舞台时，英文像跟读模式那样先遮住，并循环播放。
- 按键：`R` 或点一下揭开英文；`1` 到 `3` 评级并进入下一项；`→` 不评级跳过；`Space` 暂停；`Esc` 退出复习。
- 舞台上方有一条横栏，写着「复习 3 / 12」，有分段时加上段名，旁边是三个评级按钮。
- 复习结束时，结束卡片统计各个评级的数量，并提供把评为「没记住」的句子再过一遍的入口。

**跨集复习从首页开始。**

- 首页多一张卡片，写着「复习收藏 · 还在练 42 句，来自 5 集」，点开后进入同一个模式，队列覆盖整个媒体库：
  剧集按库里的顺序排列（先文件夹，再散放的文件），每集内部按播放顺序。
- 队列里的一项如果在另一集或另一段，先走现有的打开流程把它打开，再跳到那一句，和现在从别的段重播收藏的做法完全一样。
  所以评级由当时打开的那一集写入，走现有的 `POST /lingualab/notes`。
- 剧集已经不在的项会被跳过，并计入小结。

**服务端（host）多一条只读路由。**

```ts
// GET /lingualab/review: every kept sentence not ticked done, across the library.
export interface ReviewPayload {
  readonly ok: boolean
  readonly reason: string | null
  /** Episodes with at least one such sentence, in library order. */
  readonly episodes: readonly ReviewEpisode[]
  /** Sentences across all of them. */
  readonly total: number
}

export interface ReviewEpisode {
  readonly episode: string
  readonly title: string
  readonly kind: 'folder' | 'file'
  /** Its segment ids in play order; empty for an episode without segments. */
  readonly segments: readonly string[]
  /** Not-done phrases, in play order. */
  readonly phrases: readonly NotePhrase[]
}
```

这条路由读取文件夹剧集的 `notes.md`，以及插件状态里文件剧集的收藏，用的解析器和安全检查都和 `GET /lingualab/notes` 一样。
它从不写入。

**不在这次范围内：**

- 排期（到期日、间隔重复）以及任何逐句的复习历史，这些需要在行格式里加新字段。
- 本次练习小结之外的统计。
- 把五步移出抽屉。
- 在复习横栏里编辑备注。

## Alternatives considered

- **保留勾和两个标签，只在上面加复习。** 要改的少，但让人困惑的正是这三个互不相关的标记；复习时先要求评级，
  再让用户自己去设标记，等于问了两遍。
- **带到期日的间隔重复。** 复习清单自然会发展到这一步，但它需要每一句的历史（上次复习时间、间隔），行格式里放不下。
  加一列就改动了一个用户会手工编辑、agent 也会 grep 的格式。现在的评级为它留了余地：以后的 note 可以在同样的四个状态上加排期。
- **保留抽屉，只去掉遮罩。** 改动更小，但右侧会有两个面板争用宽度，列表也仍然盖在它要控制的舞台上。
- **单独的复习页，带自己的播放器。** 描述起来更清楚，但要重复实现播放器、字幕处理和打开分段，这些练习页都已经有了；
  而且用户复习时就用不上练习时用的字幕、变速和循环。
- **在浏览器里汇总整个库的笔记，每集一个请求。** 不用改服务端，但五十集的库，首页卡片要先发五十个请求才能显示一个数字。

## Consequences

- 笔记抽屉、它的遮罩和时间按钮都去掉了；之前为时间按钮修的暂停问题，成了卡片的正常行为（`Space` 和控制栏始终可用）。
- `#review` 和 `#hard` 现在表示最近一次的评级，而不是哪一天没想起来。旧文件也能自然地读：带 `#review` 的行显示为「模糊」，
  带 `#hard` 的行显示为「没记住」。
- 单词气泡从一个词改成一段，所以舞台上的词需要有选区状态；单击的行为和原来一样。
- `1`、`2`、`3` 成为快捷键，并加入「更多」里的按键列表。
- `N` 原来和 `S` 一样是收藏键；现在它切换右栏，收藏只用 `S`。
- 新路由意味着 `dsh-plugin.naming.json` 和 README 的路由表要改，服务端也要重启。`check-host.mjs` 不用改：
  它通过 `src/shared/protocol.ts` 里的路径常量读取路由。`ReviewEpisode` 还带上了这一集的分段 id，
  这样前端（client）给队列排序的方式和服务端一致。
- 复习时不记录听到哪里：复习在收藏的句子之间跳来跳去，记下这些位置会把「继续」挪到复习最后停下的地方。
  听到哪里只在复习开始时记一次。
- 复习时按 `←` 回到上一项，可以重新评级；提案里只写了 `→`。
- 从媒体库外打开的剧集不在跨集复习里，因为服务端列出的是库扫描找到的内容；这类剧集的句子仍然可以在它自己的「收藏」栏里复习。
- 回到首页时，先把还在防抖等待中的评级写入，首页再重新读取复习数量，所以数量里不会包含刚评过的句子。
- 已有的 `notes.md` 保留原来的开头说明：开头原样保留，所以只有新建的文件才用解释评级的那一段。
- 卡片按播放顺序排列（先按段，再按时间），不按收藏的先后，和复习的顺序一致。
- Figma 里的 `Notes / Light` 画板不再与页面一致；需要补一张「收藏」栏的画板和一条复习横栏。
- 七条上限那篇 note
  （[2026-10-08-seven-phrase-ceiling](2026-10-08-seven-phrase-ceiling.zh.md)）
  主张通过取舍让待练清单保持简短。评级就是这种取舍，而且是边听边逐句做出的，而不是事后去打勾。
