# Agent Note: 五步与设置抽屉占右栏的位置

Status: implemented

## Problem

练习页右侧有三块面板，看上去不像同一个页面。右栏（「字幕 496 | 收藏 1」）在顶栏下面，宽
`clamp(300px,34cqw,440px)`，头部 48px，左边一条淡线。五步和设置两个抽屉却从页面最顶上开始，遮罩把顶栏也盖住；
宽度固定是 440px 和 420px，不管右栏多宽；带一圈很重的阴影；头部两行，标题 18px。打开一个抽屉盖在右栏上，
看起来是另一块样子不同的面板滑过来压住了右栏。

## Decision

抽屉占右栏的位置。

- **在顶栏下面。** 抽屉和遮罩都从顶栏下沿开始（`--ll-top-h`，顶栏的 48px 加 1px 下边线）。顶栏永远不被遮住，
  开着抽屉也能点；页面本来就会在一个抽屉打开时关掉另一个。
- **和右栏一样宽。** 页面是一个宽度容器（`ll-page`），抽屉用右栏的那个 clamp 量它。页面就是行的宽度，
  所以让右栏浮起来的那个 982px，也让抽屉换成浮着的右栏的宽度。
- **右栏的外框。** 左边一条淡线，不带阴影；头部 48px，一行：标题，后面跟一段灰色小字，就像右栏的标签写
  「字幕 496」。遮罩只盖舞台。

## Alternatives considered

**只对齐细节。** 抽屉照旧盖住整页，只把宽度和间距调成一样。顶栏照样被压暗、点不到，抽屉照样是另一块面板滑过右栏；
看着不统一的地方没有解决。

**设置抽屉不要遮罩。** 换主题时能对着没压暗的舞台看效果。可遮罩也是点抽屉外面关掉它的地方，五步抽屉同样需要；
两个抽屉背后的处理不一样，又是一处新的不统一。

**设置做成右栏的第三个视图。** 右栏的标签说的是这一集（字幕、收藏），设置是页面的工具。这样五步抽屉也会变成
唯一一块这种面板。

## Consequences

抽屉头部没有了 18px 的标题和第二行：五步的计数和设置的说明跟在标题后面同一行，抽屉窄的时候用省略号截断。
设置正文的左右内边距从 20px 改成 16px，和右栏头部一样。布局参考里加了一节写这些规则。
