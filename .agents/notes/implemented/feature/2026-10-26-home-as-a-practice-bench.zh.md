# Agent Note: 首页是一张练习台，五步就摆在上面

Status: implemented

## Problem

v0.18.0 的首页把库列得很清楚，却把练法漏掉了。一次练习就是那五步（无字幕盲看、英文字幕精看、跟读模仿、
次日复习、周日复习），可首页说不出下一步该做哪一步，只有打开一集之后的五步抽屉知道。用户要先打开一集
才知道自己练到哪，而这正是首页本来该回答的问题。

舞台本身也有几处小毛病。整段文件的位置只写一个 `11:04`，下面那根条常常是空的，于是数字看着像时长，
条看着像坏了。加文件的入口有四个（「添加文件」「浏览已有的文件」、拖放那一行、「选择文件」），其中两个是
同一件事。复习那一块把同一个数说了三遍。音频文件的大小混在练习相关的信息里。整页是一条窄栏，区块之间
压着细线，看起来像设置页，不像干活的地方。

## Decision

首页按一张练习台来排，先在画布上做了两个方向的设计稿，这里采用方向 A：

- **舞台**是左边一张带框的卡片，也是全页最大的东西。它写上次是什么时候听的（「接着上次 · 2 小时前」，
  取自书签的 `updatedAt`），停在哪里（`11:04 / 22:41`，条填到这个位置），这一集的五步（五根条，各写用了
  多久或建议多久），以及一个实心按钮，按钮上写它要去的那一步（「继续跟读模仿」）。按钮旁边一行写音频从哪里
  接着放。
- **右栏**放每周复习（一个大数字，下面最多列三集来源）和唯一一张加一集的卡片。往页面任意处拖文件照样能导入，
  文件悬在页面上时这张卡的边框变成品牌色。
- **剧集表**在库里多于一集时出现在练习台下面：听到哪里、五根小条、收藏了什么。筛选按每集在五步里的进度分成
  在练、没开始、练完。练完指五步都勾上，不是音频听到了结尾。
- **页脚**只有一行：左边是文件夹，右边是构建版本。

五步的定义从五步法抽屉那个 widget 挪到了 resume feature，抽屉和首页读的是同一份五步。页面在原来的听到位置
旁边，再保留一张每集勾选记录的表。首页只展示勾选，勾选本身仍在抽屉里做，因为计时在那里。

舞台和首页都是尺寸容器。舞台窄于 500px 时五步改成一步一行，首页窄于 560px 时两侧留白收窄。手机和竖放
在宿主侧栏旁边的 iPad 拿到的是为它们排的布局，不是挤成一团的五列。

## Alternatives considered

**今日清单（方向 B）。** 当作每天的固定流程读起来更顺，但「今天」需要日期，而勾选记录里没有日期：哪一步
是哪天做的没有记下来，次日复习和周日复习就排不准。等勾选带上时间戳以后可以再考虑。

**保留原来的布局，只修细节。** 空的进度条、重复的按钮、说了三遍的数字都能就地修好，但漏掉的练法补不进去：
窄窄的舞台上放不下五步，除非把按钮挤到首屏以下。

**在首页上直接勾选步骤。** 能省去打开一集，但计时在抽屉里跑，首页上勾一下却不计时，会和旁边显示的用时
对不上。

## Consequences

首页除了听到的位置，现在还读 `dsh-lingualab:steps`。宿主同步带来新数据时，以及用户从一集里回到首页时，
两样都会重读。

旧首页是一个 777 行的文件，记在体量门的 baseline 里；现在每个区块一个小文件，baseline 里对应的记录都消掉了。
`locale.ts` 因为新文案变长，baseline 也随之记了下来。

四个分段样式表搬进了 `shared/lib/sheets/`，因为 `shared/lib` 已经到了 Steiger 允许的模块数，首页的样式表
再加进去就会超。
