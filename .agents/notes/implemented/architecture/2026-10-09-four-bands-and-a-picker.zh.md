# Agent Note: 练习页四条横带，素材靠浏览来挑

状态：已落地

## Problem

两条抱怨，其实是同一个形状。页面是一摞等重的卡片——播放器、字幕、媒体目录、笔记、五步——
于是眼睛不知道该先看哪里，而一个两个月才动一次的设置，和你每天都写的笔记摆在同一层。
另外，「练什么」只能靠一个原生 `<select>` 选剧集标题，而喂给它的扫描只看子文件夹；
媒体库根目录本身也只能往输入框里手打绝对路径。

## Decision

**页面是四条横带。** 48 像素的顶栏（返回、当前剧集、笔记与五步与媒体目录三个芯片），
一块钉住当前那一句的舞台连同运输条，字幕列表是唯一会滚的区域，再加 32 像素的快捷键提示行。
原来的标题与副标题删掉了：练习页上，剧集名就是标题。除了列表没有东西会滚，
于是「再听这一句」不会连同它所属的那一句一起滚走。

**不听东西的时候用到的一切都是浮层。** 选剧集、记笔记、设媒体目录，用完即走。
笔记层在宽页面上挤压列表而不是盖住它，在窄页面上改成覆盖；两种情况下当前句都在舞台上。

**素材靠浏览来挑。** `GET /lingualab/places` 列出选择层可以走的根——每个工作区，加上媒体库自己——
只给 id，不给路径。`GET /lingualab/browse` 列出一个目录：子目录、音频文件、字幕，
以及每个音频旁边配到了哪些字幕（只看文件名）。`POST /lingualab/open` 把其中一个设为当前：
扫描已经认识的文件夹剧集，或者一个音频文件——后者记进插件自己的 profile，
字节走 `GET /lingualab/file-media/<id>/<文件>`。

**散装音频也是素材。** 直接放在媒体库根目录里的文件自成一组，也能单独打开。
扫描保持只读：它只报告，真正让它可被伺服的索引是打开的那一刻写下的。

**设置保留手打路径这条退路。** 一个不在任何工作区之下的挂载点，没有地方可以走过去，
所以目录层仍然接受绝对路径。它不再是页面开口问的第一件事。

## Alternatives considered

- **留着卡片，只把样式重做。** 更省事，也把真正的毛病留下了：五块等重的东西，
  而你在听的时候要看的那一块会滚走。
- **笔记放一栏常驻的右栏。** 列表宽度的一半用来放每小时才看几次的东西；
  上一版已经演示过这对扫字幕意味着什么。
- **留着 `<select>`，在旁边加一个「浏览」对话框。** 两套选择模型要维护，
  而下拉仍然说不出这一集有没有字幕。
- **让浏览器把路径发过来浏览。** 那会把一条插件路由变成别人服务器上的通用文件浏览器，
  白名单也就成了摆设。
- **把文件剧集的笔记写在音频旁边。** 这个插件的规矩是素材目录只读；
  音频旁边多一个 `S01E03.notes.md` 与它矛盾，还会给同一份数据开出第二个家。

## Consequences

- 客户端再也不能用路径指名一个文件；一切都走 place id 加相对路径，由 host 在 `realpath`
  之后重新校验。
- 文件剧集的笔记与它的索引条目都住在插件的 profile 条目里（`openState`），
  也就是 `libraryRoot` 写的同一个地方。笔记有两个家——文件夹剧集是 markdown，文件剧集是 profile 里的
  JSON——这是「不往用户的素材目录里写」的代价。
- 挑素材是一次请求，而不是本地状态：host 确认之前浮层不关，
  于是拒绝的理由显示在列表所在的地方，而不是跟着浮层一起消失。
- 键盘多了一层「当前行」的概念：`↑`/`↓` 只移动选择、不动音频，`Enter` 才播它。
  提前往后翻不再要拿正在播的位置来换。
