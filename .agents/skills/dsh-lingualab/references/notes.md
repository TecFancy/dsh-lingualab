# 笔记与收藏

改 `notes.md` 的格式、收藏的上限与评级、收藏怎么匹配原句时读这份。

## 格式只在一处解析

- 解析写在 `src/shared/notes-format.ts`，面板和服务端都用它，不要在任何一端另写一份正则。
- 文件剧集（id 以 `file.` 开头）的笔记不写文件，存在插件 profile 的 `openState` 里。
- 一条短语占文件的一行，所以备注里的换行写成 `<br>`，读回来再还原成换行：
  - `<br/>`、`<br />` 和大小写变体都认，`\r` 直接丢掉。
  - 和 `|` 的转义放在同一处处理。
  - 不要让原始换行写进文件，它会把这条短语截断。

## 没有 7 条上限

- `MAX_PHRASES` 是 500，只用来防止失控的客户端，服务端拒绝超长的写入。
- 工作集保持简短靠的是评级。一条收藏只有一个状态（`gradeOf` / `withGrade`），由勾和两个标签读出：
  - 勾优先；`#hard` 优先于 `#review`。
  - 评级时先清掉勾和这两个标签，再设上自己的；读者手写的其他标签保留。
  - 行格式没有为此加字段，以后也不要加。
- 右栏「收藏」的「还在练 / 已记住」视图按评级筛选，不靠上限。**不要**再加回询问用户替换哪一条的弹层。
- 原先的取舍记在 `.agents/notes/implemented/feature/2026-10-08-seven-phrase-ceiling.md`，那是当时的决定，不要改它。

## 收藏怎么对上原句

- 收藏的句子按「段 + 整秒 + 文本」匹配（`keptSentenceKey`），因为 `notes.md` 只存整秒。不要改回直接比较浮点时间。
- 重播收藏也用这个键找回原句（页面的 `keptCueStart`）；直接跳到整秒会落进上一句后面的空隙。
- 段写在 `notes.md` 的 `## <段 id>` 标题里，不写进收藏行。
